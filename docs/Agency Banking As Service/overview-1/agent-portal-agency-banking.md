On the agent's portal, agents can process non-cashout transactions using their web browsers.

This platform's main users are agents, who can view their information such as name, account number, types of transactions carried out, and wallet details, including balance.

###Users
-----------------------------
As seen in the image below, agents can add users, edit their profiles, change passwords, and so on. The agents can edit or update their profile, update photos, transaction pins, names, and all of the agent’s information. This feature can be accessed by clicking on the down arrow icon with an image symbol on the top-left corner of the dashboard.
