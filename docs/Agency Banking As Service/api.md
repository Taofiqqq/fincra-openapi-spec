We offer robust APIs that allow you to create your agency banking platform and offer services such as bill payments, cash withdrawals, and many more. Our offered APIs are as follows:

1. [Cashout API](/reference/card-transaction): With this API, you can withdraw funds from a POS system. Please check the API guide for instructions on using it and the API Reference for a list of all available endpoints.

2. [Utility Payment Service](/docs/utilities-overview): With this API, you can pay bills such as electricity, airtime, and many more. Please check the API guide for instructions on using it and the API Reference for a list of all available endpoints.
