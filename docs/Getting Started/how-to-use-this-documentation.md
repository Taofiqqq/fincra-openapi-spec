This section of the documentation provides you with an overview of all the endpoints currently offered by Fincra. One of the key features of our API documentation is the ability to test these endpoints using our API explorer. Below, you will find valuable guidance on how to effectively navigate, comprehend, and utilize the API documentation, along with its unique functionalities.

It is highly recommended not to skip the introductory portion of any API section, as it contains essential information necessary for efficiently utilizing the APIs.

To test any endpoint, simply include your API key in the authentication header, and you will be ready to proceed.

While the API explorer is helpful, please be aware that it may not support all endpoints. For comprehensive testing, we recommend using your Postman application or a similar tool.
