In this section of the documentation, you will find all the endpoints Fincra offers at this time. A major feature the API documentation provides you with is the functionality to test these endpoints with our API explorer. Below you will find how to effectively study, understand and use the API documentation and its unique features.

* Avoid skipping the introduction portion of any API section because it contains all the information you need to know to utilize the APIs effectively.
* Simply enter your API key in the authentication header of any endpoint you want to test, and you'll be good to go.
* Please don't rely entirely on the API explorer because it might not support all endpoints; instead, test the endpoints with your Postman application or any similar application
