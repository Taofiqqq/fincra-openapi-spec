## Currency Pairs

A currency pair is the quotation of two different currencies, with the value of one currency being quoted against the other. We have two types of currency pairs which are conversion currency pair and disbursement currency pair.

 **Conversion Currency Pairs**

| EUR-NGN | USD-NGN |
| :------ | :------ |
| EUR-GBP | USD-EUR |
| GBP-NGN | NGN-EUR |
| GBP-EUR | NGN-GBP |
| USD-EUR |         |

 **Disbursement(Payout) Currency Pairs**

| USD-EUR | GBP-NGN |
| :------ | :------ |
| USD-NGN | GBP-GHS |
| USD-GBP | GBP-KES |
| USD-KES | GBP-UGX |
| USD-GHS | NGN-NGN |
| EUR-EUR | NGN-EUR |
| EUR-NGN | NGN-GBP |
| EUR-GBP | NGN-KES |
| EUR-GHS | NGN-UGX |
| EUR-UGX |         |
